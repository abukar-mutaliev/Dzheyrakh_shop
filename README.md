# Магазин

White-label витрина на Next.js. Название, цвета, контакты, категории и доставка задаются в `shop.config.js`. Товары и заказы лежат в self-hosted Supabase. Покупатель оформляет заказ без регистрации и платит через СБП.

- Пример переменных приложения: `.env.local.example`
- Стек для VPS: `infra/supabase`
- Команды для нового клиента: `docs/vps-new-client.md`
